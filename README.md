## 🏗️ Systems I've Built

### 🎓 Oneness eLearning Platform (Microservices Ecosystem)

A comprehensive, event-driven educational platform built as a scalable microservices architecture. This system integrates cohort management, real-time analytics, dynamic curriculum structures, and AI-powered media processing and other microservices into a single cohesive ecosystem.

* **Cohort Management:** cohort course management, student enrollment, seat allocation, schedule management, and assessment release.
* **Learning Analytics:** Real-time tracking of learning velocity, completion forecasting, drop-off detection, leaderboard, and certification generation.
* **Curriculum Engine:** Hierarchical course structuring with dynamic reordering, tree-based navigation, breadcrumb generation and bulk content operations.
* **Google Calendar Synchronization:** OAuth2-authenticated calendar provisioning, incremental event mapping, and webhook integrations for cohort based learning and assessment .
* **AI & Media Processing:** Automated video transcription, learning content summarization, and video processing.

**Core Technologies:** `NestJS`, `PostgreSQL`, `Apache Kafka`, `Eureka`, `Redis`, `Python`, `Gemini AI`, `Whisper AI`

---

### 💾 Automated PostgreSQL Database Backup Engine

A transaction-safe Python utility designed to preserve data integrity across live production databases.

* Engineered an automated backup utility using `psycopg2` to execute complete exports while preserving schemas, constraints, and indexes.
* Optimized large-scale data extraction by implementing PostgreSQL's native COPY format for high-throughput, memory-efficient handling of binary data.
* Enforced strict data integrity through read-only, transaction-bound operations with automated error rollback to mitigate corruption risks.
* Streamlined administrative workflows with scheduled automation, dynamic timestamped file generation, and detailed execution logging.

**Core Technologies:** `Python`, `PostgreSQL`, `psycopg2`

---

### 📄 Multithreaded Bulk Image-to-PDF Pipeline

A highly concurrent file processing architecture engineered for massive document datasets.

* Developed a processing pipeline utilizing Python's `ThreadPoolExecutor` to concurrently convert massive, nested directories of scanned images into PDFs.
* Designed a memory-efficient batching architecture capable of handling thousands of high-resolution images simultaneously without memory overflow.
* Integrated on-the-fly image compression via the `Pillow` library, drastically reducing storage footprint while maintaining document clarity.
* Built robust execution tracking using `tqdm` for real-time visualization and detailed logging to intelligently skip processed directories.

**Core Technologies:** `Python`, `ThreadPoolExecutor`, `Pillow`, `tqdm`
